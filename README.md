# BMW-Sales-Analysis-Dashboard--Power-BI
Developed an interactive dashboard using BMW sales data (2010–2024) from Kaggle. Built KPI metrics using DAX and performed data cleaning in Power Query.  The dashboard visualizes sales trends, model performance, fuel-type contribution, and price vs mileage analysis.

## Dashboard Features
- KPI Cards (Sales, Revenue, Avg Price, Mileage)
- Year-wise Sales Trend
- Top-Selling BMW Models
- Fuel-Type Distribution
- Price vs Mileage Analysis

## Tools Used
- Power BI
- DAX
- Power Query

## Dataset
Source: Kaggle

## Key Insights
- Sales are concentrated in a few top-performing models
- Electric vehicles show growth potential
- Premium models contribute higher revenue
